Ambient API test

Checks how many photos the Google Photos Ambient API returns for your album, and whether other people's photos are included.

1. Credentials

Use an OAuth client of type "TVs and Limited Input devices" in a project with the Ambient API enabled. These stay in this browser only.

2. Sign in and choose the album

3. Count the photos

Each run uses roughly 25 to 60 of the 240 requests allowed per device per day.
